# Faults — руководство пользователя

**Версия приложения:** 0.0.1
**Дата обновления:** 25 августа 2026 года

## Назначение

Faults — инженерная система для ведения проектов, регистрации неисправностей,
работы с Kanban-доской и базой знаний.

## Вход и выход

1. Откройте страницу `/login`.
2. Введите имя пользователя и пароль.
3. После успешной проверки откроется дашборд.
4. Для завершения сеанса нажмите «Выход» в нижней части боковой панели.

Авторизация хранится в cookie текущего браузера. Сеансы Firefox и Chrome независимы:
в каждом браузере необходимо войти отдельно.

## Ресурсы интерфейса

Стили, иконки и JavaScript-библиотеки поставляются вместе с приложением. Интернет
для загрузки Bootstrap, Bootstrap Icons и Axios не требуется. Это устраняет различия,
возникавшие при блокировке внешнего CDN браузером, расширением или сетевым фильтром.

После обновления проекта рекомендуется один раз выполнить принудительное обновление
страницы (`Ctrl+F5`), чтобы браузер заменил ранее закешированные CDN-ресурсы.

## Важные ограничения

- Вход действует только в том профиле браузера, где он был выполнен.
- Очистка cookie завершает текущий сеанс.
- Визуальное отображение следует проверять в актуальных версиях Firefox и Chrome.
